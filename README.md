## Who is Nijat Hummatović?

I am a **Cloud & DevOps Engineer** specialising in AWS infrastructure automation, Terraform-based Infrastructure as Code, and CI/CD pipeline design. With hands-on experience operating production environments on **AWS and Azure**, I build systems that are observable, reproducible, and built to last.

My core belief: if a human is doing it repeatedly, a machine should be doing it instead. I apply that thinking across infrastructure provisioning, deployment automation, and database operations on both relational and NoSQL systems.

Outside of day-to-day engineering, I founded **[Douklar](https://github.com/douklar)** — a dedicated DevOps automation project combining private and open source tooling, built to eliminate repetitive work across the entire DevOps lifecycle.

> 🔭 Currently building new tooling under [Douklar](https://github.com/douklar)
> 🤝 Open to collaboration on DevOps automation, cloud infrastructure, and IaC projects
> 💬 Ask me about Terraform, Kubernetes, AWS architecture, or CI/CD design
